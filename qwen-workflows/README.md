# Qwen Image 2.1 INT8 / FLUX — ComfyFloatBar

## Модели на сервере ComfyUI

| Папка внутри ComfyUI/models | Файл |
| --- | --- |
| diffusion_models | qwen_image_2.1_int8_convrot.safetensors |
| text_encoders | qwen3vl_8b_int8_convrot.safetensors |
| vae | qwen_image_2.1_vae_bf16.safetensors |
| model_patches | qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors |

Используются UNETLoader с weight_dtype=default, CLIPLoader с type=qwen_image,
TextEncodeQwenImage21, QwenImage21Cache, KSampler и VAE именно от версии 2.1.
По умолчанию: 25 шагов, Euler, simple, CFG 1, denoise 1. В глобальных настройках
можно выбрать INT8 или qwen_image_2.1_bf16.safetensors; энкодер остаётся INT8.
При выборе Qwen показывается ползунок шагов (1–80), отдельно для каждого раздела.
GGUF и LoRA не нужны
для основных графов приложения. Веса и энкодер — INT8; VAE — BF16.

Нужна версия ComfyUI с поддержкой Qwen Image 2.1 (официальные шаблоны используют
узлы версии 0.37.0). Приложение проверяет наличие узлов и моделей перед отправкой.
Единственную подходящую модель в подпапке находит автоматически; при нескольких
одноимённых файлах точный путь задаётся в qwen_workflows.js.

Для сохранения цветов нужны [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes)
и его Python-зависимость color-matcher. При наличии ColorMatchV2 приложение выбирает
её, иначе использует ColorMatch. Если обеих нет, показывает понятную ошибку;
можно установить дополнение на сервере либо отключить «Сохранять исходные цвета».

## Управление в панели

- Enhance: выбор FLUX / Qwen распространяется на обычное редактирование,
  автоматическое улучшение по фрагментам, изменение объекта по маске и совмещение.
  Для FLUX используются прежние Klein 9B и Fill. Expand всегда использует Qwen;
  выбора FLUX и ограничения полей в 400 px в этом разделе больше нет.
- «Сохранять исходные цвета»: применяется к редактированию и автоматическим
  фрагментам обеих моделей. Метод MKL, сила 100% по умолчанию. Можно уменьшить силу,
  выбрать Reinhard / Histogram + MKL либо отключить коррекцию для изменения цвета.
  RGB корректируется отдельно; прозрачность результата восстанавливается без изменений.
- Авто: все исходные фрагменты экспортируются до генерации первого результата.
  Результаты не используются в качестве источника следующих фрагментов.
- Генерация, img2img и AI-мокапы: Qwen добавлена рядом с Turbo и Krea 2.
  Существующее улучшение prompt через Gemini сохранено.
- Remove Background: переключение BiRefNet / Qwen. Настройки края относятся к
  BiRefNet, у Qwen есть отдельный редактируемый prompt.
- AI-мокапы → Обои: «Удалить белую стену после генерации» запускает второй проход
  Qwen. Удаляется главная белая стена, сохраняются мебель, пол и остальные детали.
  В Photoshop исходный дизайн размещается под интерьером отдельным слоем.
  Оригинальный мокап до удаления стены также вставляется скрытым слоем
  Original__BeforeWallRemoval. Его можно использовать для восстановления лишних
  вырезов. Копия оригинала сохраняется рядом с результатом с суффиксом __Original.
  Опция не применяется к режиму «Картины».
- «Освободить память ComfyUI»: проверяет общую очередь выбранного сервера и
  отправляет POST /free с unload_models=true, free_memory=true. Не отменяет задания.
  Ответ подтверждает приём запроса, а не точное количество освобождённой памяти.

## Прозрачность

Официальный шаблон удаления фона использует prompt:

    Remove the background, and output a PNG image

В приложении он уточнён: требуется RGBA, прозрачный фон и сохранение объекта.
Для мокапов используется отдельное описание удаления только белой стены.
Выход декодируется VAE 2.1 и сохраняется как PNG с альфа-каналом.
Приложение проверяет наличие как видимых, так и прозрачных пикселей перед вставкой.
Это проверка наличия прозрачности, а не точности выделения стены или объекта.

Удаление фона — генеративный проход: мелкие детали могут измениться.
Референс для удаления фона обрабатывается примерно в 1 MP, затем результат
возвращается к исходным размерам холста. BiRefNet остаётся альтернативой.

## Файлы

- Qwen21_INT8_t2i.json — официальный визуальный граф генерации.
- Qwen21_INT8_image_edit.json — визуальный граф редактирования с Color Match.
- Qwen21_INT8_background_removal.json — официальный визуальный граф удаления фона.
- Ep32 / Ep33 ... INT8.json — копии присланных графов: загрузка переведена с GGUF
  на INT8 safetensors, указан INT8-энкодер, LoRA выключены, добавлен перенос цвета.
  Их вспомогательные Pixaroma/JPS/preprocessor-узлы сохранены и могут требовать
  собственных дополнений. Для минимального запуска используйте три графа выше.
- api/ — плоские API-графы для проверки интеграции. Имена input.png / mask.png /
  mockup.png заменяются именами загруженных изображений. Маска inpaint хранится
  в альфа-канале: прозрачная область означает область редактирования.

Qwen «Изменить объект» и Expand используют ModelPatchLoader → Apply Fun ControlNet
(ZImageFunControlnet) с входами inpaint_image и mask. Эти узлы входят в ComfyUI
0.38.0; отдельный пакет ControlNet не нужен. На ранней экспериментальной версии
приложение автоматически выбирает QwenImage21FunControlNetApply и переименовывает
вход image в control_image. Модель Union загружается из model_patches, не через
ControlNetLoader. Дополнительные библиотеки поверх зависимостей ComfyUI не нужны.

В Expand ImagePadForOutpaint формирует расширенный холст и маску новых областей.
Union получает их через настоящие каналы инпейнтинга, сила 1, диапазон 0–1.
Canny не используется: контур пустых полей мешал бы дорисовке. Текстовый энкодер
видит только исходную картинку без пустых полей и не добавляет reference latent.
Размер рабочего холста отдельно задаётся через ImageScaleToTotalPixels и EmptyLatentImage.
Рабочее разрешение около
1 MP; итог возвращается к точным размерам расширенного холста. После генерации
результат составляется по маске с оригиналом: исходная часть сохраняется пиксельно.
Промпт должен описывать всю желаемую сцену. Качество продолжения зависит от сцены.
PNG результата Expand сначала сохраняется в download/Generations. Photoshop
расширяет холст на заданные поля и принимает результат в исходный документ.
Если вставка невозможна (например, исходный документ закрыт или изменён), сохранённый
PNG открывается отдельным документом. Если Photoshop закрыт, PNG остаётся на диске.

Проверка 01.10.2026 на ComfyUI 0.38.0, INT8, 25 шагов:
- изменение красной кружки на синюю завершилось за 45 секунд; пиксели вне маски
  полностью совпали с исходником;
- расширение 512×512 → 832×672 завершилось за 41 секунду, без пустой рамки;
  исходная область 512×512 полностью совпала с оригиналом;
- интерфейсный тест проверяет передачу полей и исходного documentId в Photoshop.
  Эта проверка подменяет Photoshop и не редактирует пользовательские документы.

## Проверки

`npm test` — графы, выбор моделей, сохранение альфа-канала в цепочке Color Match,
наличие моделей/узлов, запрос освобождения памяти и занятая очередь.

`electron tests/ui-smoke.cjs` — панель в Chromium с заменёнными Photoshop/ComfyUI:
генерация, модели, фрагменты, удаление фона/стены, порядок слоёв и кнопка памяти.
Не выполняет реальную генерацию и не меняет документы Photoshop.

Проверено на установленном ComfyUI 0.37.1 / RTX 3090: реальное редактирование Qwen
и FLUX с переносом цвета, прозрачный PNG и отдельный неизменённый оригинал.
В окружение этого ComfyUI установлен color-matcher 0.6.0.
В Photoshop 2026 проверены порядок слоёв и скрытый оригинал с исходными размерами.
Переключение BF16 и числа шагов проверено на уровне графов и интерфейса;
реальные генерации выполнялись на INT8.
